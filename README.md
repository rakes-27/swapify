# Swapify 🔄

**Swapify** is a community item exchange platform that allows users to list items, discover items from other users, send exchange requests, and manage their trades through a centralized platform.

## 🚀 Live Demo

**Live Website:** YOUR_LIVE_WEBSITE_URL

## 📌 About the Project

Swapify was developed as a complete web application rather than a simple CRUD project.

The platform focuses on creating a structured item-exchange workflow where users can manage listings, interact with other users, request exchanges, and track their trading activities.

The project also includes an administrative system for managing users and platform activity.

## ✨ Features

- 🔐 User authentication and session management
- 📦 Item listing and management

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd swapify
```

### 2. Configure the database

Create a MySQL database and import the provided database SQL file.

Update the database configuration with your local credentials.

### 3. Configure the application

Update the project base URL and database configuration according to your local environment.

### 4. Run the project

Place the project inside your PHP server directory such as:

```text

```

Then start Apache and MySQL and open the project through your local server.
